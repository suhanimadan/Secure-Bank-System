
# Bank Management System

A console-based banking system built in C++.

## Features

- Create new accounts
- Login system with PIN authentication
- Deposit and withdraw money
- Transfer funds between accounts
- Change account PIN
- Admin panel
- Account search and management
- Bank summary system

## Concepts Used

- Functions
- Arrays
- Loops
- Conditional Statements
- Modular Programming
- Authentication Logic
  

## Used
- Code::Blocks

## Current Status

Completed core banking operations and admin management system.
